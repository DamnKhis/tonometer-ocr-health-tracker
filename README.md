# 🩺 Tonometer Health Tracker Bot

Асинхронный Telegram-бот для автоматического распознавания показателей артериального давления и пульса с экрана тонометра по фотографии с последующим логированием в персональную Google Таблицу.

Проект решает проблему рутинного ручного ведения дневника гипертоника / мониторинга здоровья.

---

## 🚀 Ключевые возможности

- 📸 **Computer Vision / OCR через VLM:** Использование мультимодальных моделей через Groq API (с поддержкой резервных ключей и пула запросов) для точного извлечения цифр с сегментных ЖК-экранов тонометров.
- 🕒 **Парсинг EXIF-метаданных:** Автоматическое извлечение точного времени и даты создания оригинального фото, даже если они не отображаются на самом приборе.
- ✏️ **Интерактивная валидация данных (FSM):** Перед записью пользователь видит распознанные параметры в удобной карточке и может в один клик скорректировать любое поле (систолическое, диастолическое, пульс, дату, время, комментарий) через Inline-кнопки.
- 📊 **Мультипользовательская интеграция с Google Sheets:**
  - Автоматическое создание отдельного листа для каждого пользователя (`user_id`).
  - Форматирование заголовков и закрепление первой строки.
  - Автоматическая сортировка записей по дате и времени в хронологическом порядке.
  - Дедупликация (защита от повторного сохранения одной и той же записи).
- 🛡 **Отказоустойчивость и безопасность:**
  - Кастомный `Sliding Window Rate Limiter` для соблюдения лимитов Vision API.
  - Механизм `Single Instance Lock` (защита от запуска дублирующих процессов polling'а).
  - Обработка `TelegramRetryAfter` (Flood control) и предобработка тяжелых изображений (PIL).

---

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Фреймворк бота:** `aiogram 3.x` (FSM, Magic Filter, Router architecture)
- **AI / OCR:** `OpenAI Client` -> `Groq Cloud Vision API`
- **Таблицы:** `gspread`, `google-auth`
- **Обработка изображений:** `Pillow` (нормализация ориентации, кроп, контрастирование для OCR)
- **Конкурентность:** `asyncio`, `ThreadPoolExecutor` (для неблокирующего выполнения синхронных SDK)

## ⚙️ Установка и локальный запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/your-username/tonometer-bot.git](https://github.com/DamnKhis/tonometer-ocr-health-tracker)
cd tonometer-bot
```

### 2. Создание виртуального окружения
```bash
# Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка Google Service Account
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. Включите **Google Sheets API** и **Google Drive API**.
3. Создайте **Service Account**, сгенерируйте JSON-ключ и сохраните его в папку `utils/` под именем `service_account.json` (или укажите путь в `.env`).
4. Создайте Google Таблицу и **поделитесь доступом** (роль: Редактор) на email сервисного аккаунта (`xxx@xxx.iam.gserviceaccount.com`).

### 5. Конфигурация переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOprstUVWXyz       # Токен от @BotFather
GOOGLE_SHEET_ID=  # ID из URL вашей таблицы
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json     # Имя файла ключа в utils/
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxx              # Основной ключ Groq API
RESERVE_GROQ_API_KEY=                                # (Опционально) Резервный ключ
GROQ_MODEL=qwen/qwen3.8-27b                          # Модель для распознавания
```

### 6. Запуск бота
```bash
python main.py
```

## 📋 Пользовательский сценарий (User Flow)

1. Пользователь отправляет в чат фото экрана тонометра (как сжатое фото или как файл).
2. Бот выполняет предварительную обработку кадра, проверяет EXIF-теги и отправляет запрос в Vision LLM.
3. Бот присылает распознанные данные с клавиатурой подтверждения:
   ```text
   Распознанные данные:
   Верхнее: 120
   Нижнее: 80
   Пульс: 72
   Дата: 2024-05-12
   Время: 08:30

   Проверьте данные и нажмите Сохранить или отредактируйте поле.
   [ Сохранить ]
   [ Изменить верхнее ] [ Изменить нижнее ]
   [ Изменить пульс ]   [ Изменить дату ]
   [ Изменить время ]   [ Изменить примечание ]
   ```
4. При нажатии на сохранение бот синхронизирует строку с листом пользователя в Google Таблице и сортирует записи.
